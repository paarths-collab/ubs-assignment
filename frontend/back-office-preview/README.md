# Back Office frontend preview

This is a static, public preview of the AI Data Analyst interface. It contains the homepage, interactive browser-local charts and chat based on included synthetic sales data, and documentation. It does not connect to the Python API; sign-in, uploads, saved work, and AI answers are available only in the full application with separately hosted backend services.

Build with `npm ci && npm run build`. Next.js exports the static site to `out/`.
